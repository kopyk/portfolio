Projects

ask-my-docs

Python · Claude API · Retrieval-augmented generation · MCP server

A command-line tool that answers questions about a folder of Markdown documentation. It finds the relevant sections, sends them to Claude, and returns an answer with sources. The companion tutorial builds a simplified version step by step.

  • 56 pytest tests pass, and a retrieval eval scores Recall@4 at 10/10 on frozen fixtures (10 questions, so a rough check rather than a precise score).
  • GitHub Actions CI runs the tests on Python 3.10 and 3.13 and fails the build if Recall@4 drops below 100%.
  • An MCP server exposes the same retrieval as a search_docs tool for Claude Code and Claude Desktop.
  • CHANGELOG written from the real commit history.
