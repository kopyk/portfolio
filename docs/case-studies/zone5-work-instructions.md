**Role:** Technical Writer II, Zone 5 Technologies, June 2026 to present.

## Problem

A product configuration changed, and the work instructions that assemblers follow had to change with it. In an AS9100 quality system, each work instruction is a controlled document: its revision has to match the current design, and the set has to stay consistent with itself.

[JORDAN: one or two sentences, in general terms, on what made this hard. For example: the number of documents, shared steps across documents, or work continuing on the floor during the change.]

## Approach

- **Led the move of the work-instruction set to the updated configuration,** keeping revision control and configuration alignment intact across every document. [JORDAN: how did you track which documents were affected and which were done? Describe the method, not the content.]
- **Worked from engineering source material.** Turned CAD models and engineering drawings into step-by-step procedures for assemblers.
- **Brought a second set of 35 documents up to the same work-instruction standard.** [JORDAN: what did "the standard" cover, in general terms? Structure, step wording, how warnings are shown?]
- **Coordinated daily** with manufacturing engineers, mechanical engineers, assemblers, technicians and the manufacturing execution team so that instructions matched the current design.
- **Led First Article Inspection documentation** for one side of the program and wrote 11 new work instructions for it.

## Result

- 28 AS9100-compliant work instructions and build documents developed and maintained.
- First article completed on time.
