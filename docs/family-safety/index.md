- **A fictional platform, not a real one.** Help content about a real product has to match the live product step for step. I could not test that, so I designed a small, consistent set of controls for a made-up platform called Kitewood.
- **One concept page, then tasks.** A guardian needs to know what a control does before changing it, so the concept page comes first and each task links back to it.
- **The problem page is written for a stressed reader.** It opens with what to do right now, puts the emergency line before the steps, and tells the guardian what happens after they send a report.
- **Reading level is a test, not a hope.** The build fails if any page in this set scores above grade 8.

</AboutSample>

:::note Sample content
Kitewood is a fictional platform. These guides are a writing sample. They do not describe any real product.
:::

Kitewood is a place where kids build and play games made by other players. These guides are for the adult who looks after a child's account.
